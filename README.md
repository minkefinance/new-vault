# New Vault Submissions

This repository is the official registry for submitting `new-vault` applications. To add a new vault, you must submit a Pull Request (PR) following the strict guidelines outlined below. 

## 🚨 PR Requirements

Every Pull Request must include the following two mandatory pieces of information. **PRs missing this information will be automatically rejected.**

1. **DFIOracle Contract Address**: The verified smart contract address of the DFIOracle.
2. **DFIOracle Description**: A detailed explanation of the oracle, focusing specifically on the **token emission rules** (release schedule, distribution mechanics, and halving cycles).

---

## 🛠️ How to Submit

1. **Fork** this repository.
2. **Create a new branch** for your vault (e.g., `feat/new-vault-xyz`).
3. **Fill out the Pull Request template** completely when opening your PR against the `main` branch.
4. Wait for the automated checks and core team review.
