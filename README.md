# New Vault Submissions

This repository is the official registry for submitting `new-vault` applications. To apply for a new vault, you must open a new Issue using our official template.

## 🚨 Submission Requirements

Every issue must include the following two mandatory pieces of information. **Submissions missing these details will be closed immediately.**

1. **DFIOracle Contract Address**: The verified smart contract address of the DFIOracle.
2. **DFIOracle Description**: A detailed explanation of the oracle, focusing specifically on the **token emission rules** (release schedule, distribution mechanics, and inflation/halving models).

---

## 🛠️ How to Submit

1. Navigate to the **Issues** tab of this repository.
2. Click the **New Issue** button.
3. Select the **New Vault Application** template.
4. Fill out the structured form completely and click submit.
